# Personal Blog System

一个功能完整的个人博客系统，支持文章、项目、动漫、日记等多种内容类型。

## 功能特点

- 📝 文章管理
- 🚀 项目展示
- 🎬 动漫追踪
- 📅 日记记录
- ⚔️ 技能展示
- 📸 相册功能
- 📢 公告发布

## 技术栈

- **前端**: React 19 + TypeScript + Tailwind CSS
- **后端**: Node.js + Express + Prisma + PostgreSQL
- **部署**: Docker + Nginx

## 开发历程

本项目从零开始，经历了以下阶段：

1. 基础架构搭建
2. 核心功能开发
3. 界面美化
4. 性能优化
5. 功能完善
