这是我的第一篇博客，用 Markdown 写的！🎉

## Markdown 的优势

Markdown 让写作变得简单：

- **轻量级** - 不需要复杂的编辑器
- **可读性强** - 纯文本，容易阅读
- **版本控制友好** - Git 也能管理
- **易于迁移** - 到处都用 Markdown

## 代码示例

```typescript
const greet = (name: string) => {
  return `Hello, ${name}!`;
};

console.log(greet('World'));
```
