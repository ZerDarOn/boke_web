# 博客项目启动

今天正式启动了 INK.SPIRIT Blog 项目的开发工作。

## 项目目标

- 创建一个个人博客系统
- 使用现代技术栈
- 支持 Markdown 内容管理

## 技术选型

### 前端
- React 19
- TypeScript
- Vite
- Tailwind CSS

### 后端
- Node.js
- Express
- Prisma ORM
- PostgreSQL
