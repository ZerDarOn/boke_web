# 版本 2.0 发布

INK.SPIRIT Blog 版本 2.0 正式发布！

## 新增功能

### Markdown 内容导入
- 支持拖拽上传单个/多个 Markdown 文件
- 自动解析 Front Matter 元数据
- 批量导入功能
- 冲突处理（覆盖/跳过）

### MinIO 对象存储
- 集成 MinIO 对象存储
- 支持分布式部署
- 图片自动压缩和缩略图生成

### 性能优化
- 优化数据库查询
- 添加缓存机制
- 前端性能提升

## 改进

- 修复了文件上传功能
- 优化了搜索功能
- 改进了用户界面
- 修复了一些 bug
